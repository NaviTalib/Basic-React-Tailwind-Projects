# 🔢 React + Tailwind CSS Counter App

A responsive, interactive counter application built to practice **React state management** and **Tailwind CSS utility classes**.
```
---

## 🛠️ How It Works & What Was Used

### React Fundamentals
* **`useState` Hook:** Used to manage the application's single source of truth—the `count` state.
* **Event Handling:** Inline `onClick` handlers directly trigger state updates for incrementing, decrementing, and resetting values.

### Tailwind CSS Styling & Layout
* **Flexbox Layout:** Utilizes `flex`, `flex-col`, and `items-center` to perfectly center content on all screen sizes.
* **Responsive Breakpoints:** Uses Tailwind modifiers (`sm:`, `md:`) to dynamically adjust font sizes and button padding across mobile, tablet, and desktop views.
* **Interactive UI:** Styled with hover states (`hover:bg-blue-700`) and smooth state transitions (`transition-colors`).

## 🚀 How to Install & Run

### Prerequisites

* [Node.js](https://nodejs.org/) (v16.0 or higher)
* `npm` (comes pre-installed with Node)

### Setup Steps

1. **Navigate to the project folder:**
   ```bash
   cd path/to/counter-app

```
```
2. **Install project dependencies:**
```bash
npm install
```


3. **Start the development server:**
```bash
npm run dev

```


4. Open your browser and go to `http://localhost:5173` (or the local URL displayed in your terminal).
