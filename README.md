# Basic React + Tailwind CSS Practice Projects

A collection of basic React mini-projects and UI components built while learning **React** and **Tailwind CSS**. This repository serves as a personal sandbox for practicing component structure, state management, and modern utility-first styling.

---

## 🚀 Tech Stack

* **Frontend Library:** React
* **Styling Framework:** Tailwind CSS
* **Build Tool:** Vite
* **Package Manager:** npm

---
